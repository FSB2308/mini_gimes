Mini Games 
About the Project
Mini Games is a simple web development project featuring two classic games: Rock Paper Scissors and Tic-Tac-Toe. Players can compete against the computer in both games.

This project was created as part of my web development learning journey. I used an educational tutorial as a starting point and made some personal modifications.

Games
Rock Paper Scissors 
A classic game where the player competes against the computer by choosing rock, paper, or scissors.

Tic-Tac-Toe 
A classic X and O game where the player competes against the computer.

Technologies Used
HTML
CSS
JavaScript
Learning Objectives
Practice JavaScript fundamentals.
Understand basic game logic and user interactions.
Improve HTML and CSS skills.
Learn by modifying an existing educational project.
